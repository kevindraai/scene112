# Original duty building shells

Two source-authored Dutch public-service building shells replace the existing visible blockout inside the current footprints. No original scene logic, geography, floors, interactions, physics, signs, vehicles or interiors are included/changed. No real agency branding is authored. Runtime GLBs contain only render geometry and named render groups.

Build both original models/maps/manifests from any working directory:

```sh
blender --background --factory-startup --threads 1 --python-use-system-env --python-exit-code 1 --python /absolute/repository/source/3d/duty_buildings/build_duty_buildings.py
```

Blender4.3.2/glTF addon and NumPy are the verified authoring tools. The builder resolves final repository paths through `__file__.parents[3]`; helper/texture field source are local, with no cross-family import. Default builds perform zero renders. Optional `-- --preview` stays under ignored source/previews. `.gdignore` excludes the editable packed .blend files from native Godot imports. Do not distribute Python caches or .blend1 backups.

`bureau_shell.glb`:18,210 triangles/two consolidated meshes/six materials. Local front+Z/up+Y/metres, mount root at world(0,0,-4.5). Front wall localZ+4.5; exact4.6m opening betweenX±2.3, clear toY2.9. Detailed split masonry/coursework around real front/side window gaps, deep cast reveals, framed/mullioned/transomed recessed glass, sills/lintels, concrete damp courses, open entry portal, shallow cap, low hipped zinc roof, standing seams/ridge, gutters/downpipes and two service vents. Original navy front panel is reproduced with native vertex tint; original world signs remain separate. No new door/floor blocks the passage. Render groups/meshes: BureauFacade/BureauFacadeSurface and BureauRoof/BureauRoofSurface.

`kazerne_shell.glb`:15,198 triangles/three consolidated meshes/six materials. Same conventions; mount at world(29,0,-6.4). Front localZ+4.9 exactly maps to existing worldZ−1.5. Columns at localX−10,−3,+4,+10, width.45, height4.3; open bays6.55/6.55/5.55m wide and4.3m high. Red facade lintel, deep high-level side windows, cast column/damp-course details, low depot zinc roof/seams/ridge/vents/drainage. Stored roller cassettes/curtain ribs/motor casings/guide rails remain within columns or above the4.3m openings; no lowered shutter obstructs a truck. Render groups/meshes: KazerneFacade/KazerneFacadeSurface, KazerneRoof/KazerneRoofSurface, GarageMechanisms/GarageMechanismSurface.

Both stay within existing roof envelopes: bureau19.4×9.49m under original19.5×9.5; kazerne21×11m exactly matches original roof. The taller low-pitched roof is visual; root's original collision ceiling stays authoritative. Bureau roof underside≈4.76m and kazerne ceiling underside5.65m align with existing roof physics. No threshold/step/ground surface is exported.

Six shared PBR materials: original red Dutch brick, cast concrete, zinc roof metal, painted powder steel, recessed trim/gasket, transparent window glass. Fifteen original512px maps support the five opaque materials; glass is a simple thin alpha/PBR surface. Every primary UV layer is explicitly replaced with physical surface coordinates, preventing the earlier street primary-UV pitfall. Masonry tile2.1m has10 columns/30 courses (brick pitch≈.21×.07m); source field derives from the project's own street generator with tracked local adaptation. Painted details use the validated ACTIVE COLOR0 path; joined geometry explicitly retains the real tint layer. Source and native import tests assert actual blue/red frieze values, not merely an existing vertex-color field.

Both .blend files pack all15 maps. They were copied into a texture-free normalized layout, reopened and exported byte-identically. An independent full builder from a fresh normalized layout also generated byte-identical GLBs with the verified4.3.2 toolchain; no claim is made for other Blender versions. Native builds consume embedded-image GLBs without Blender. Individual manifests/hash lists document this content.
