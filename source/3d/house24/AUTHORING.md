# Huis24 accessible ground floor

`build_house24.py` is a separate original SCENE112 M3 visual asset. It keeps the existing DutchTerrace6.8×7m masonry footprint,4front windows, brick/timber/sill proportions, pitched clay-tile roof, ridge caps, gutters and chimney. The roof overhang is unchanged. Street brick/roof/wood maps are regenerated by an isolated copy of the project's texture authoring code at the original seeds and1024px, retaining the actual street appearance. New original512px cloth/plaster/ceramic maps are generated in the isolated helper. No paid/downloaded assets, brand marks or external image dependency are used. Project license: private/proprietary docs/LICENSES.md.

The previous full .68m-high solid brick plinth is replaced by actual perimeter strips and front courses split around the door. `WalkableFloor` is a distinct render mesh whose actual top is Y.02. The doorway has1.215m clear width between casing inner edges and2.24m clear height. Its shallow threshold reaches Y.0305. There is no dark backing plane in the doorway, no raised floor across entry and no static door leaf baked into the shell. Ground windows can reveal the real room; upper-window recess/curtains visually dress the inaccessible upper storey.

Root node `BurningHouse24` is placed at world(-2,0,48), feetY0, front-Z. `DoorPivot` local(-.59,0,-3.555) owns `DoorLeaf`; setting its Godot rotationY to−PI/2 opens inward along the left side. Optional `WindowPivot` under `MasonryShell` owns the hinged left ground-floor casement `WindowLeaf`; its closed rotation is0. `GroundFloor` contains named `WalkableFloor`, `GroundFloorCeiling` and `InteriorLiningSurface`. Ceiling bottomY2.755, inner plaster sides atX±3.0575. Root must align camera/physics walls and ceiling to these dimensions.

Interior props are original fitted objects, consolidated into fifteen meshes total with semantic roots retained: LivingSofa/sideboard, kitchen cabinets/sink/tap/fridge, a neutral portable appliance and lead/outlet, a book shelf with storage and a coffee table/cup. `FuelFront`, `FuelOrigin`, `FuelSide` match the three FireCase fuel positions; their individual render surfaces can receive per-instance scorch material overrides. Duplication of relevant materials prevents coloring other meshes that share the original wood/metal material. An appliance/lead is contextual scenery, not a predetermined verdict about the fire cause.

Exact local anchors: CellFrontAnchor(0,.55,-1.6), CellOriginAnchor(-1.8,.55,1.8), CellSideAnchor(1.8,.55,1.7), VictimAnchor(-.8,0,-1.8), EntranceAnchor(0,0,-4). Add the root world origin to get existing FireCase/FireSite coordinates. Existing scene registrations, fire targets, smoke/flames, occupant/door safety, nozzle rays, collision and save state are all owned by Root FireSite. The GLB exports none of those behaviors or physics bodies. Root should remove old visible shell/door/furniture blockout once using this replacement to avoid duplicate geometry.

Final source layout is self-contained `source/3d/house24/{build_house24,assetkit,street_shape,street_textures}.py` and fully packed burning_house24.blend. Native GLB/maps/manifests go under assets/models/house24 and assets/textures/house24. All paths resolve from __file__ and source/3d/.gdignore excludes authoring files. Blender4.3.2 plus NumPy/standardglTF add-on rebuilds from any CWD using an absolute script path:

```sh
blender --background --factory-startup --threads 1 --python-use-system-env --python-exit-code 1 --python source/3d/house24/build_house24.py
```

No render calls execute by default. GLB embeds images; editable .blend packs them with final-layout relative paths. Optional previews are authoring-only and excluded from native imports. Geometry/import/real capsule-door checks are in validation; these do not substitute for integrated fire gameplay/native visual acceptance.
